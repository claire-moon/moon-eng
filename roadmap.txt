2. MDP EDITOR 

  - MODULE: PALedit
      - Import 8-bit BMP palettes
      - Canvas viewer (Display the 256 color grid)
      - Export palette chunk for MDP compiler
  - MODULE: TEXedit
      - Import raw sprites / textures
      - Canvas viewer (Display asset with applied PALedit palette)
      - Texture Compositor (Combine raw patches into full textures)
  - MODULE: MAPedit
      - Top-down 2D grid canvas
      - Entity / Sector placer
  - MODULE: AUDIOedit
      - Import WAV/VOC/MIDI files
  - CORE: MDPedit COMPILER
      - I/O (Filetree Browser widget reading MDP headers/directories)
      - Archive Compiler (Pack all module outputs into a single .mdp binary)
